# AI Players (NeoForge 1.21.1)

Автономные ИИ-игроки с мозгом на языковой модели (Claude).

## Как получить .jar

### Вариант 1: GitHub Actions (проще всего, ничего ставить не нужно)
1. Создай пустой репозиторий на GitHub и залей туда всё содержимое этой папки.
2. Открой вкладку **Actions** - сборка запустится сама (или нажми *Run workflow*).
3. Когда она станет зелёной, скачай артефакт **aiplayers-jar** - внутри `aiplayers-1.0.0.jar`.

### Вариант 2: локально
Нужны JDK 21 и Gradle 8.8+ (или готовый Gradle wrapper из официального NeoForge MDK).
```
gradle build
```
Готовый файл: `build/libs/aiplayers-1.0.0.jar`.

## Установка
Положи jar в папку `mods` (и на сервер, и клиентам - у сущности есть свой рендер).

## ИИ-мозг
Задай переменную окружения `ANTHROPIC_API_KEY` там, где запускается игра/сервер.
Модель по умолчанию `claude-haiku-5-5`; сменить можно переменной `AIPLAYERS_MODEL`.
Без ключа боты просто бродят.

## Команды (нужны права оператора)
- `/aiplayers spawn <кол-во> [радиус]` - создать ботов вокруг себя
- `/aiplayers clear` - удалить всех ботов в мире

## Что умеют боты
- Живут в списке игроков (Tab) как обычные игроки.
- Отвечают на приветствие: если быстро присесть рядом (2+ раза за 3 секунды), бот повернётся и присядет в ответ.
- Говорят в чате только по-русски, сами пишут о планах, просят ресурсы, отвечают игрокам.
- Каждый бот - личность со своим характером; цель - выжить и построить свою базу.
- Сами проектируют дома: размер, высота, форма крыши (плоская, двускатная, шатровая), дверь, окна и материалы
  случайные, поэтому дома не повторяются. Нужно от 80 блоков (доски, булыжник, брёвна); со стеклом будут окна.
- Крафтят по настоящим рецептам, плавят, охотятся, едят, спят в кровати, ставят факелы в темноте,
  убегают при низком здоровье.

Ники ботов латиницей: ограничение Minecraft на имена в списке игроков (до 16 символов, A-Z, 0-9, _).
